Вот краткий справочник возможностей бота:

📋 Основные возможности Logseq бота
1. Управление задачами
📊 Просмотр задач: /tasks - показывает все задачи с фильтрацией

💼 Рабочие задачи: /work - только рабочие задачи

🏠 Личные задачи: /personal - только личные задачи

📈 Статистика: /stats - аналитика по задачам

2. Голосовой ввод 🎤
Отправьте голосовое сообщение → задача автоматически создаётся в journals/ГГГГ_ММ_ДД.md

Автоматически распознаёт:

Дедлайны: "завтра", "15 февраля", "в пятницу"

Приоритеты: "срочно", "важно"

Теги: #работа, #личное (через Ollama)

3. Мотивация
💪 /motivate - общая мотивация по всем задачам

💼 /motivate_work - мотивация только по рабочим задачам

🏠 /motivate_personal - мотивация по личным задачам

4. Фильтрация
🎯 /filter - выбор статусов для отображения (TODO, DOING, DONE, NOW, LATER)

⏰ /set_time - установка времени уведомлений

🌍 /set_timezone - настройка часового пояса

5. Уведомления 🔔
📊 Ежедневная сводка по задачам

⚠️ Оповещения о просроченных задачах

💼 Напоминания о рабочих задачах (9:00-18:00)

6. Настройки
⚙️ /settings - все настройки бота

🔔 /notifications - управление уведомлениями

🔒 Белый список - доступ только для владельца

7. Поддерживаемые форматы Logseq
text
- TODO Задача
- DOING В процессе
- DONE Выполнено
- NOW Сейчас
- LATER Потом
- WAITING Ожидание
8. Примеры голосовых команд
text
"Купить молоко завтра" → задача с дедлайном на завтра
"Срочно сдать отчет 15 февраля" → высокий приоритет + дедлайн
"Позвонить маме в пятницу" → задача на пятницу
Бот полностью интегрирован с Logseq и использует локальную Ollama для классификации задач! 🚀
